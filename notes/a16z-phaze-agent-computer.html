a16z 投资 Phaze：Agent 的下一站不是 API，而是一台电脑

Vibehood　·　2026-11-09　·　摘要约 760 字　·　阅读原文 ↗

API 只能覆盖软件愿意开放的能力；剩下的大量专业软件，最通用的接口是一台可以被完整操作的电脑——而 Agent 让「按需一台工作站」从福利变成基础设施。

核心要点

  • 融资：Phaze 875 万美元 Seed 轮，a16z 领投，Indie、NextView、Makers Fund、Lerer Hippeau 参与；未披露估值/收入/客户数。
  • 团队：Benjy Boxer 与 Chris Dickson，此前创办 Parsec（低延迟远程桌面，2021 年以约 3.2 亿美元卖给 Unity），a16z 也是 Parsec 早期投资人。
  • 问题：大量企业内部系统、桌面软件、Blender/Unreal/CAD 没有完整 API，且依赖特定 OS、GPU 与本地环境 → Computer Use 成为通用执行层。
  • 真实商业逻辑不是「远程办公」：一家大型制造企业约 3 万台工程工作站、每台超 1 万美元、硬件投入超 3 亿美元，但利用率很低。Phaze 把「设备所有权」变成「计算资源使用权」。
  • Agent 放大需求：一个工程师一台机器，一个团队却可能同时跑多个 Agent（测试、渲染、监控、IT），各自需要独立执行环境 → 企业计算资源的计量单位从「员工数」变成「数字劳动力数」。
  • 风险：Computer Use 的可靠性、延迟与安全仍未解；能用 API 完成的任务没必要绕 GUI；高价值操作需要审批。

值得记住的结论

判断 Agent 基础设施时，别只看 Model Serving / Sandbox / Runtime，还要看「它有没有地方把事情真正做完」。工作站池化是这条链上被低估的一环。
