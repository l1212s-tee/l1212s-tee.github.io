用 REA 逆向复刻 Microsoft Word：8.6 万星项目实测

杉森楠　·　2026-10-12　·　摘要约 669 字　·　阅读原文 ↗

REA = Reverse Engineer Anything，一个 MCP server + Agent Skill + CLI，把 Hopper/Ghidra/IDA 统一成一套接口；作者用约两到三成 Pro 额度复刻出像素级 Word。

核心要点

  • 项目热度：8.6 万 star；9 月发布时几乎无增长，10 月初 10 天从几千涨到 8 万+，近一个月 99% 的下载来自这波。
  • 形态：npx rea-agents setup 一条命令接入，自动配置 17 个客户端（Claude Code、Codex、Cursor、Gemini CLI、Devin、OpenCode、Copilot CLI 等）。
  • 分工：REA 自己做界面解读、图标提取、窗口观察等简单部分；复杂逻辑调用 Hopper/Ghidra/IDA 取伪代码；核心价值是把多家逆向引擎统一封装，Agent 不必关心底层用哪个。
  • 成品：界面接近 1:1 像素还原，排序、标题、加粗、批注、插入表格、图片对齐、视图切换、专注模式基本可用；细节交互仍粗糙。
  • 成本：约一个 Pro 级别会员额度的 20%~30%。
  • 一个坑：用 Claude Code 装 REA，Claude 会要求用正版 Hopper；换 Codex 不会。

值得记住的结论

逆向复刻正从少数专家的手艺变成普通开发者可用的产品开发方式。被低估的不是模型能力，而是「成熟软件的行为本身就是最好的规格说明书」。
